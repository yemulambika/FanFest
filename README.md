# MERN Stack Project

This is a MERN (MongoDB, Express, React, Node.js) stack project.

## Project Structure

```
/client    -> React app built with Vite (JavaScript)
/server    -> Node.js + Express + MongoDB API
```

## Setup

### Client
```bash
cd client
npm install
npm run dev
```

### Server
```bash
cd server
npm install
npm run dev
```

## Scripts

- `npm run dev` (client): Starts Vite development server
- `npm run dev` (server): Starts nodemon for API development
